Generate Synthetic Dataset

Generate additive supplier workflow records. The full assignment dataset uses 10,000 purchase orders and at least 15,000 acknowledgement/change events. Smaller values are available for isolated testing.

Ground-truth scenarios

The generated business records include four labeled scenario examples. Ground-truth labels are exported separately and are not stored as business-record fields.

A generation is additive and idempotent for the same seed and configuration. Repeating it does not add duplicate database rows.

Files are stored under the generated_data folder in a batch-specific directory. SQL output is a seed script only; it is not executed.
